**Description :**  
Vel-Home est le site internet d'une entreprise fictive, réalisé dans le cadre d'une SAE lors de ma première année de BUT Informatique. L'objectif principal était de concevoir une interface tout en maîtrisant les bases du développement web statique.

**Fonctionnalités :**
* Création d'une identité visuelle pour une entreprise fictive.
* Développement d'une Home-Page structurée et ergonomique.
* Mise en pratique des standards du web (HTML5 / CSS3).
